# Household Chores

A shared household chores manager for roommates.

Roommates are treated as equal peers, and the app owns the rota:
recurring chores automatically rotate between roommates on their
own schedule, so nobody has to negotiate who does what. Completing
a chore earns points, and the household shares one dashboard
showing the current rota, anything overdue, and a points leaderboard.

Built with Django.

See [`_docs/plan.md`](_docs/plan.md) for the full plan.
